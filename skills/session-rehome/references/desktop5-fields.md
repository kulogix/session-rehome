# Desktop 5 record fields (5.11492.0)

The 138 session-record fields Claude Desktop 5.11492.0 can write that ccd-rehome 0.11.1 did not know, and how
0.11.2 handles each. Classified on 2026-11-12 from Desktop's own code (the macOS build's JavaScript: who writes
each field, who reads it, and what a load under another account, without the field, or on another machine
does); then each risky or uncertain class was re-derived by a second reader trying to refute it, which changed 9.
`references/mechanics.md` §5a summarises the classes and cites the code for the key facts. The lists are
`ACCOUNT_BOUND`, `TRANSIENT`, `HOST_BOUND` and `KNOWN_KEYS` in `scripts/ccd-rehome`; the self-test moves a
record holding all of them.

Also in this group, outside the 138: `interruptedAwaitingPerson` (known since 4.x) moved to account-bound,
because Desktop clears it together with `interruptedByQuitAt`, `interruptedByQuitFor` and
`interruptedUnseenResume`; `cuGrantFlags` (4.x) became host-bound, because Desktop clears it together with
`cuAllowedApps` and `cuFlagsGrantedAt`; and dropping `remoteControlSpawn` sets `remoteClientLimits: true` and
`remoteControlDescendant: true` (the clamps that keep a session started from Remote Control out of bypass
permissions and under Desktop's Remote Control restrictions). `cutTurn` was moved to account-bound when 0.11.2 was
reviewed.

## Account-bound: dropped by every move to another account (and by export/adopt) (20)

| Field | What it is | Why this class |
|---|---|---|
| `artifactsMcpVouchedCalls` | Tool calls whose artifactUuid Desktop vouched as served by the account's claude.ai artifacts MCP (verified dynamic http server). | artifactUuid values are artifacts owned by the old account, and Desktop itself scopes this data by account:org. |
| `backgroundTaskSuggestions` | Queue (at most 20) of pending background-task / side-session suggestions, i.e. spawn_task chips the person has not acted on. | Kept under another account, an accepted cloud suggestion would start a cloud session in the old org's environment or pool and fail with a server error. |
| `cloudSessionId` | Id of the claude.ai cloud session that mirrors this local session (the 'violin bow' cloud-sync feature). | A server-side id in the old org's cloud. In 5.11492.0 the loader discards it anyway (gate stubbed to false), and the CLI re-reports it, so dropping is harmless. |
| `cloudSpawnedTasks` | Background-task suggestions this session launched as cloud sessions: taskId plus cloud sessionId. | The ids are the old org's cloud sessions, so the links do not open under another account. |
| `connectorWireNames` | Mapping between claude.ai connector uuids and the readable wire keys used in CLI tool names (mcp__<key>__tool). | Keyed by the old account's connector uuids and the companion of remoteMcpServersConfig (ACCOUNT_BOUND). |
| `cutTurn` | SSH-only state of a turn cut short by an app quit or a host kill: {at, state owed\|interrupted, why, limitMinutes, serverUpdatedAt}. | Under a claude.ai sign-in Desktop's check that the person continuing is the same compares two empty keys, so an owed turn would continue on its own under the new account, which the quit-resume marks are dropped to prevent. Desktop rebuilds the notice from the record; the conversation is intact. (changed on review of 0.11.2) |
| `emailAddress` | claude.ai account email of whoever started the session. Copied from the renderer's start params and carried to forks and restarts. | The old account's identity (personal data), never re-derived, so it is wrong under another account. |
| `enabledMcpTools` | Per-session MCP tool on/off map. Keys are "<connectorUuid or local server name>:<tool>". | Mirrors per-account state. The first toggle in the moved session would replace the new account's disabled-tool set with the old map. |
| `interruptedByQuitAt` | Quit mark for a turn that was running when Desktop quit; at the next launch Desktop auto-sends a continuation if the mark is under 24 h old. | Desktop refuses to auto-resume for a different person. In 1p mode it relies on the per-account folder for that, and a cross-account move breaks it: the new account would auto-send a continuation of the old account's turn. |
| `interruptedByQuitFor` | The signed-in person key (third-party/gateway mode) of whoever ran the CLI at quit. | Identity value derived from the account or sign-in (signedInPersonKey). |
| `interruptedUnseenResume` | Loop guard: the quit interrupted an auto-resume the person never saw, so Desktop must not auto-resume again. | Inert without interruptedByQuitAt. Dropping it while keeping that mark would remove the loop guard, so it must share interruptedByQuitAt's class. |
| `movedToCloud` | Pending marker set after the session was handed to the cloud. | Kept under another account, the session is auto-archived at launch and a Settle goes to a cloud session in a different org. |
| `remoteControlFollowsStarter` | Child session started by Claude in an RC lineage that should follow its starter's Remote Control. | Direct analogue of remoteControlAutoEligible (already ACCOUNT_BOUND). |
| `remoteControlKeptServerCopyId` | Id of the session's server-side Remote Control copy on claude.ai that Desktop still owes an archive or delete call. | A server id from another org. Desktop's only check (signedInAsLoadedAccount) passes after a move, so the archive call would go out under the wrong account. |
| `remoteControlLiveAtUpdateQuit` | Marker that RC was live when Desktop quit for an update. Used to restore RC at the next launch within 1 hour. | It embeds the old accountId. Desktop ignores and later clears a foreign marker, so dropping is harmless. |
| `remoteControlSpawn` | The claude.ai (CCR) Remote Control session the conversation was started from and is shared with. | A server id from the old org. The reattach would fail under the new account, and the mismatch path can issue a server delete. |
| `remoteControlUserEnabled` | The user's explicit Remote Control on/off choice for this session. | A stored true auto-connects RC under the new account, exposing the session to that account's claude.ai and phone without fresh consent. |
| `servedConnectorCalls` | Connector tool calls served by Desktop's MCP coordinator: toolUseId plus connector uuid and tool. | Connector uuids belong to the old org. Desktop's guard passes after a move because homeTenancy becomes the new account. |
| `spaceId` | Id of the Space ('Project') the Code session was started in; children and forks inherit it. | Under another account or org the id names a Space that does not exist in that account's spaces.json, which ccd-rehome never moves for Code. |
| `sshReattach` | Handle for re-attaching to the surviving remote process: processId, hostKey, checkpoint, state adoptable\|reap_only\|blocked, policySig, remoteControl, helperInstanceId, and person (a u-<32hex> key derived from the signed-in account). | Desktop's check that the re-attaching person is the same works only in third-party mode; for a claude.ai account it compares two empty keys and passes. Kept on a move to another account on the same machine, Desktop would re-adopt the old account's surviving remote CLI, whose environment carries the old account and org. (changed on review) |

## Transient: dropped by every move (Desktop recreates them) (6)

| Field | What it is | Why this class |
|---|---|---|
| `coveredError` | The older error card that is hidden behind a session_stale_relogin card and restored after the person signs in again. | Valid only while error and errorAt (both TRANSIENT) exist and match it. |
| `errorCategory` | Category of the error card (for example session_stale_relogin, crash_loop_backoff, remote_turn_interrupted). | Meaningless without error, which is already TRANSIENT. The session_stale_relogin value describes the old account's sign-in, so keeping it would show a wrong card under the new account. |
| `errorCode` | A {at,code} refinement of the error card (restarts_paused, worktree_verify_*, ssh_host_limit_N, ...). | Only valid with a matching error, errorAt and category. Dead once those are dropped. |
| `peerInbound` | In-flight peer messages queued to this session: uuid -> {from, messageId, written, engineQueued, cancelRequested, steers}. | Desktop clears it on every load unless an SSH reattach is live. |
| `restartErrorMark` | The errorAt of a card saved by the SSH refused-start retry, used to recognise that card later. | Only compared with errorAt (TRANSIENT). If dropped, the comparison fails and nothing happens. |
| `tccFolderKind` | The kind of macOS privacy-protected folder (TCC) behind a 'macOS blocked access to the working directory' error banner. | It belongs to error/errorAt, which are already TRANSIENT, and Desktop always sets and clears them together. |

## Host-bound: kept by moves on this machine, dropped by `adopt --cwd` on another (32)

| Field | What it is | Why this class |
|---|---|---|
| `btwSharedTree` | Absolute path of another session's worktree that this /btw side chat works inside (shared checkout). | On the same host it must be kept: it is the ownership guard against running inside another session's worktree. |
| `cuFlagsGrantedAt` | Time the computer-use flag grants (clipboardRead/Write, systemKeyCombos) were given; the TTL anchor for dispatched sessions. | A grant on this machine. Desktop clears it together with the host-bound cuAllowedApps when the host changes. |
| `folderPlace` | Folder-identity pin {cwd,realPath,origin?} or {cwd,lost:true}, used to confirm that the session folder still leads where it did. | Holds host realpaths. Absent is fine: it is rebuilt fresh. A stale value after adopt --cwd becomes permanently lost:true and blocks folder reads and writes. |
| `folderWorktrees` | Worktrees Desktop made for the session's extra folders. | Local paths to working trees. They must be kept on account moves (losing them orphans the trees) and are meaningless on another host. |
| `keepCoversOwnTree` | Flag: the kept-dirty state covers the session's own tree, not only its extra-folder trees. | Part of the kept-dirty unit tied to a local tree. Keep it on the same host and drop it with the others on adopt. |
| `keptDirtyAt` | Timestamp that starts the expiry clock for an archived session's kept dirty worktree. | Part of the kept-dirty unit that describes a tree on this host, so keep it on same-host moves. |
| `keptDirtyWorktree` | Flag: the archived session's worktree was kept on disk because it had uncommitted changes. | Describes a local dirty tree. Keep it on same-host moves (it drives the storage list, discard and expiry). |
| `keptWorktreeLeftover` | A worktree directory Desktop let go of but could not remove, {path,baseRepo}. | Host paths that are targets for directory removal. Keep on the same host so Desktop can finish the cleanup. |
| `knownStartedByHostLauncher` | Last known state of whether this SSH host's admin launcher starts Claude Code; used to show a 'setup changed' notice. | A fact about the SSH host that only affects a notice row (it returns early for non-SSH sessions). |
| `launcherAtSpawn` | Whether the attached or surviving process was started through the organization's or host's launcher. | Scoped to the process on this host and recomputed at every spawn. |
| `launcherUsedAppSignIn` | The launcher-started CLI asked for this app's sign-in (its launcher exported no credential). | Scoped to the process, has no meaning without launcherAtSpawn, and is cleared at every process bind, so it is grouped with launcherAtSpawn. |
| `pendingSystemReminder` | System-reminder blocks waiting to be prepended to the next user message: worktree and fork notes, surface notice, side-session and CI notes, project folders, scratch workspace notes. | On the same host the content is accurate and owed to the model, so keep it. |
| `requestedAdditionalFolders` | Extra folders requested when the session started, [{path,useWorktree?,sourceBranch?}], re-applied on every restart. | Local folder paths. Dropping them on the same host loses the extra folders and their worktrees on the next start. |
| `scratchCarried` | {from:[scratchWorkspace, readFrom], to:destFolder, left:[relpaths]}. | Pure local path mapping. Valid on the same host and meaningless elsewhere. |
| `scratchFilesLeftIn` | Path of the scratch workspace a session left when it moved folders without every file copied. | A local path. On the same host the leftover folder still exists. |
| `sharedTreeGone` | {tree:path, by:ownerSessionId}. Set when the session owning a shared tree releases it. | On the same host, dropping it loses the graceful move-to-scratch recovery, and the session would try to run in a deleted tree. |
| `sshAddressNeverEdited` | True from the creation of an SSH session until its host address is edited. | A companion to sshConfig that only drives an advice row. It is inert without sshConfig. |
| `sshConfig` | The SSH target the session runs on: {sshHost, sshPort, sshIdentityFile, remoteCwd}. | Another account on the same host: still valid, and the new org's policy is applied again at dial. |
| `sshForeignDaemonLossAt` | Time a foreign daemon instance reported the process unknown; nothing automatic runs for 20 minutes. | A 20-minute hold that stops Desktop starting a second remote CLI while an older daemon may still be running the first. (changed on review) |
| `sshHostChangedAt` | Time the SSH target was found answering as another host. It holds automatic recovery and hidden shells until a person continues. | A safety hold with no expiry that Desktop does not recreate, so it is not TRANSIENT. |
| `sshKillRecoveryGrantedAt` | Time an automatic restart was granted after the remote process died; used to detect a repeated kill within 10 minutes. | This is the repeat-kill brake. Its in-memory partner sshProcessLossRecoveries is never saved, so this persisted timestamp is the only thing that carries the brake across the Desktop restart a move requires. (changed on review) |
| `sshProcessLossStoodDownAt` | Time automatic recovery was stood down after repeated remote process losses. | A 10-minute stand-down that sshAutomaticRecoveryHeld reads, including in the launch pass. (changed on review) |
| `sshRemoteProcessId` | Id of the Claude Code process running on the SSH host for this session. | Not account-bound. After an account move Desktop refuses re-adoption (person_changed) and uses this id to kill the old account's still-running process before it resumes fresh. |
| `sshRemoteTranscriptPath` | Cached path of the conversation's .jsonl on the SSH host. | A path on the SSH host that Desktop looks up again when it is absent, so dropping it is harmless. |
| `stagedTranscriptPath` | Absolute path of an imported session's transcript, staged in <user-data-dir>/claude-code-sessions/<acct>/<org>/imported-staging/<cliSessionId>.jsonl until the resume is confirmed. | Dropping it loses the conversation, so it must not be TRANSIENT or ACCOUNT_BOUND. |
| `tasksStoppedAt` | SSH notice mark: durable scheduled tasks in the remote folder stopped because no CLI is running there. | The launch pass only checks folders of re-adopt candidates, which need a live sshReattach and sshRemoteProcessId. (changed on review) |
| `tasksStoppedEnded` | CLI session ids (cliSessionId plus priorRemoteCliSessionIds) of the ended conversations used by the tasks-stopped re-check. | It is loaded only when tasksStoppedAt is present, and lookAgain's lock check needs it: without it, a lock left by an ended conversation reads as held and the mark is cleared. (changed on review) |
| `worktreeLazy` | Deferred (lazy) worktree created on first entry through the CLI WorktreeCreate hook: {root,openedRoot?,path?}. | Host paths. Dropping it on the same host loses the session's tree and flips it into non-lazy worktree semantics. |
| `worktreeName` | Name of the app-managed worktree; the key into the git-worktrees.json worktrees map. | Identifies a worktree on this host, so it is kept on same-host moves. |
| `worktreePath` | Path of the session's git worktree (<repo>/.claude/worktrees/<name>), usually equal to cwd. | Host path. Losing it on the same host breaks the link to the worktree, which is the costly mistake. |
| `writtenRepositories` | Up to 8 absolute paths of nested git repositories inside the session folder that the session has written to; they extend its repository and write roots. | Local filesystem paths. Keep on a same-host account move, since dropping them loses the listed nested repos. |
| `wslConfig` | The WSL distro the session runs in: {distro}. | It names a distro installed on this Windows machine. Keep it on same-host moves and drop it on adopt, like sshConfig. |

## Session state: kept (80)

| Field | What it is | Why this class |
|---|---|---|
| `_startedThroughHostCliLauncher` | Whether the session's CLI was started through the host CLI launcher (an untrusted CLI). | Security guard: at the next spawn that does not go through the launcher, Desktop resets a bypass/auto/acceptEdits mode that came through the launcher. |
| `adoptedFromOtherSurface` | The conversation began on another surface (terminal CLI or an import); on the next resume Desktop owes the model a 'you are now in Desktop' notice and does not reuse a frozen prompt snapshot. | This is conversation-surface state, not account or host state. |
| `agent` | Custom agent name chosen at start, passed to the CLI/SDK `agent` option on every spawn. | Session config. Neither account- nor host-scoped. Dropping it would silently change the session's agent persona. |
| `asides` | Up to 40 finished 'aside' answers (quick side answers to messages typed mid-turn), each {messageUuid,status:'done',text,at}. | Display/history state tied to transcript message uuids. Holds no account, server or host references. |
| `autoArchiveExempt` | Set to true when the person un-archives a session, so the inactivity auto-archive sweep leaves it alone. | The person's own 'don't re-archive' choice. Nothing in it belongs to an account or a host. |
| `autoArchiveOnPrClose` | Per-session override of the setting that auto-archives the session when its PR merges or closes. | A plain user preference for this session. |
| `autoFixDelivered` | Per-PR dedup of the CI-failure and merge-conflict wakes the auto-fix engine already delivered to the session. | Keyed by portable PR keys and tied to GitHub, not to the claude.ai account. |
| `autoFixNoticeSent` | Flag: the auto-fix instructions system reminder has been queued for, or delivered to, this CLI conversation. | Describes the conversation, which a move never changes. Dropping it re-appends the auto-fix instructions to the conversation. |
| `autoSendsPausedAfterDelete` | Set after the person's delete of this session failed: no automatic or peer messages until the person sends. | Records the person's intent and holds no ids. Keeping it is harmless and cleared by their send; dropping it would let automatic messages reach a session the person tried to delete. |
| `branch` | Git branch of the session's worktree. Desktop also uses it as the marker that a session is a worktree session. | Dropping it breaks recovery: Desktop can no longer re-lease or recreate the worktree, or bind PRs by branch. |
| `btwLoweredFrom` | The effort level a /btw side chat was lowered from. Restored when the chat is promoted to top level. | Plain model/effort state with no account or host meaning. |
| `bypassChosenInApp` | True when the person chose Bypass permissions inside the Desktop app, as opposed to it being carried in from a host-CLI launcher, a remote client or a parent session. | Twin of autoChosenInApp, which is already KEEP. The mode itself is carried by permissionMode (KEEP), and org policy removes Bypass at runtime regardless. |
| `cliMcpAppServerNames` | Names of MCP-App servers from the session's own CLI config, not Desktop's or claude.ai connectors. | Not account data, and Desktop's own importer carries it to the fresh record. |
| `color` | Sidebar color the person chose with /color or the session menu. | A pure UI preference. |
| `connectionTriesSincePerson` | Count of automatic 'Try again' attempts after connection errors since the person last sent (budget 3, at 1, 5 and 15 minutes). | Not error-card state: clearing the card keeps the count, and only the person sending resets it. Desktop saves it before every automatic try so the budget of 3 survives a restart; dropping it would grant fresh automatic tries after a move. (changed on review) |
| `contextRecovery` | Episode state of the automatic /compact recovery when the conversation's context is full. | Describes the conversation, not the account. Dropping it loses the 'context still full' gating and resets the attempt budget. |
| `conversationPluginLoaded` | Records whether Desktop's built-in conversation plugin (function hooks and asides) was mounted into the CLI at its last spawn. | A spawn-time stamp that the next spawn overwrites, so keeping or dropping it makes no difference. |
| `cutTurnChain` | SSH-only retry counters {firstCutAt, starts, continues, person} that cap automatic continues. | It does carry an account-derived hash, but Desktop itself compares it and refuses to continue for another person, so keeping it causes no wrong behaviour and no server call. |
| `cutTurnStoppedAt` | SSH-only time (ms) when the person stopped (overruled) a cut turn. | Keeping it is harmless because it is only a threshold. Dropping it while sshReattach is kept could bring back a turn the person stopped. |
| `dispatchParentId` | Id of the Cowork (local agent mode) session that dispatched this Code session. | The Code classifier resolves ids only in the Code session table, so the Cowork parent is never found and the result is 'dispatchedHere' whether the parent exists or not. (changed on review) |
| `dispatchParentOrigin` | 'local' or 'remote', the provenance of the dispatch. Marks the session as dispatched/unattended. | A provenance flag that names no account object. Dropping it would reclassify the session as attended and lift the computer-use grant TTL that the kept cuAllowedApps relies on. |
| `durableCronMade` | The conversation created a durable cron job through the CLI's cron tool. | A history fact about the session that names no account, path or process. |
| `effortInherited` | The session's effort level follows settings rather than a pinned level. | Model-settings state that belongs with effort (KEEP). |
| `endedIdleAsOf` | Marks that an SSH idle timeout ended the session's remote CLI; set equal to lastActivityAt. | Self-invalidating, with no account content. Keeping or dropping it changes at most one automatic pre-warm. |
| `forkedAtMessageUuid` | Message uuid in the parent conversation where the user forked this session. | Display-only lineage detail. It is harmless under any account or host, and dropping it loses the fork point. |
| `forkedFromSessionId` | Desktop session id (local_...) of the session this one was forked from. | A local session link. Under another account the parent is not loaded and Desktop just becomes conservative (lineage unknown); if the parent moves too the link works again. |
| `fromCliTranscript` | True when the record was created from a terminal CLI transcript (Import CLI session / Recover CLI sessions); Desktop re-infers it at load when the record id equals the CLI session id. | This is provenance, not account state. Kept under another account, it correctly suppresses a server deletion request for ids the new org never served. |
| `givenUpCliSessionIds` | Local CLI conversation ids whose resume Desktop gave up on in clearStaleResumeHandle (not /clear), capped at 100. | These ids are claims on conversation transcripts. Removed, a delete of the session leaves those transcripts behind and they look unclaimed. |
| `historyOnlyCliSessionId` | For an SSH/WSL session whose resume failed with 'No conversation found', the old conversation id is kept only so its history still shows. | This is the session's link to its conversation. Dropping it leaves an empty history and makes Desktop treat the session as a new first turn, which is exactly the costly failure. |
| `importedFrom` | Import provenance tag: '<previous-profile\|sibling-1p\|sibling-3p>-code[-elsewhere]' or 'local-1p-code'. | This is provenance plus a safety gate for content from another profile or install, not claude.ai account state. |
| `importedRunOf` | For a previous-profile import of a scheduled-task run, the key of the imported task: 'sibling-3p:code:<srcAccountId>/<orgDir>:<taskId>'. | It is only an opaque match key that groups a run with its imported task in the UI. |
| `indexedAt` | Time (ms) when Desktop first indexed the session (new session, import, CLI recovery, held first start). | A plain timestamp with no account or host meaning. |
| `isStarred` | The person's star/pin on the session. It exempts the session from auto-archive and pins its worktree in the worktree pool. | A user preference. The renderer's star sync, which resets on an account switch, can overwrite it, so keeping it is harmless. |
| `lanyardOfferPrompt` | Start capability declared by the renderer: the UI can show the 'lanyard offer' consent dialog. | A plain UI-capability flag like autoModeServerFallbackPrompt (already KEEP). |
| `lastTurnReport` | A side session's last result text (up to 400 chars) shown in the UI. | Plain display state with no ids or grants. |
| `lastTurnStopped` | UI flag that a side session's last turn was stopped. | Plain UI state. |
| `launcherMarked` | A mark that only ever turns on: the session ran through a launcher, so its CLI is untrusted (no connector calls, never named, user-only settingSources) | A security taint that Desktop itself carries to forks and imports. |
| `lineageDetached` | The session was detached from its fork or side-session parent and now shows at top level. | Plain user-chosen session state. Dropping it would re-attach a detached session to its parent. |
| `lineageDetachedBy` | Who detached the session: 'user' or 'agent'. | Companion of lineageDetached. It is local state with no account or host meaning. |
| `midTaskReplyTool` | Session-start capability flag declared by the renderer (sibling of setupTools, reportFindingsCard, turnBox). | Dropping it changes the system-prompt settings hash and removes the tool mid-session. |
| `overflowCliSessionIds` | Older local prior conversation ids pushed out of priorCliSessionIds (cap 1700) into overflow (cap 5000). | Same semantics as priorCliSessionIds, which the tool already keeps. |
| `overflowRemoteCliSessionIds` | Remote (SSH/WSL) counterpart of overflowCliSessionIds: older remote prior conversation ids. | These ids protect the local mirror copies of SSH transcripts from removal (removeQueuedSshMirrors). |
| `peerMessaged` | Sticky taint set once another session messages this one. It withdraws a scheduled run's stored and auto approvals. | A security taint. Dropping it would re-arm scheduled-task auto-approvals for a session another session has already steered. |
| `peerReceipts` | The last 20 receipts of peer messages this session sent (targetSessionId, delivery state, timestamps). | UI history and toolUseId dedupe. Desktop settles dangling pending receipts on load as 'undelivered'. |
| `pendingFirstStart` | Held first start of a session that never started: {since, options{useWorktree, sourceBranch, branchHint, title, fastMode, additionalDirectories, effortSource, permissionModeProvisional, remoteControlAtStart}, permissionMode, task, wakeParent, parentNote}. | Dropping it loses the never-started session's task and start options, which breaks starting it as intended. |
| `permissionModePicked` | A less permissive mode the person picked while an earlier mode change was still in flight. | Dropping it could leave the session in the more permissive mode (e.g. Bypass) that the person was trying to leave, so it must not be TRANSIENT. |
| `priorCliSessionLeftAt` | Map from each prior local conversation id to the time (ms) the session left it; used as a delete-safety cutoff. | Plain timestamps. Without them the cutoff falls back to the later lastActivityAt, so a transcript continued elsewhere (for example in the terminal) could be deleted with the session. |
| `priorRemoteCliSessionIds` | Earlier conversation ids of an SSH/WSL session (local priors use priorCliSessionIds instead). | These ids are claims on remote conversations and their local mirrors. |
| `prs` | PR (forge) bindings for the session's PR bar, auto-fix and auto-archive: [{prNumber,url,repo,host,branch,baseRef,state,provider,autoFix,inherited,dismissed,unconfirmed,unvouched,ownHeadRepo,notOwnRead}]. | Pure forge state, read through the local gh CLI. No claude.ai ids or grants, so it is correct under another account. |
| `queuedSideSessionNotes` | Reports from finished side sessions queued for the parent's next message. | Pending conversation content owed to the model. Dropping it desyncs it from pendingSystemReminder. |
| `recap` | An AI-generated 'while you were away' recap of the conversation, produced while the person is idle or the tab is hidden. | Derived conversation text, like promptSuggestion (KEEP). Short-lived and harmless either way. |
| `recapAt` | Timestamp of recap. | Belongs with recap. |
| `remoteClientLimits` | Security clamp: the session was started by a Remote Control client, or by Claude in a session that was. | It holds no id and makes no server call, and the provenance stays true after an account change. |
| `remoteControlDescendant` | Marks the session as a descendant of a Remote-Control-started session (Remote Control lineage). | A permanent Remote Control lineage mark Desktop never clears. It feeds permission and safety gates (no connector switching, wake auto-starts, whether the session counts as attended), so dropping it would lift restrictions. (changed on review) |
| `resumeConfirmed` | The person chose 'Trust and resume' for an imported session; set after the staged transcript was moved into ~/.claude/projects. | It is the person's own per-session trust decision on this machine, not a claude.ai grant; the Code path has no account-scoped waiver. |
| `scheduledRunContinued` | The person answered or took over a scheduled-task run, so the run counts as attended ('routineContinued'). | Every reader is gated on scheduledTaskId, so it is inert alone. |
| `scheduledTaskId` | Id of the Code scheduled task (routine) this session is a run of. | The tool's full rehome moves the task into the target account, so the id stays valid there. |
| `seenCommentIds` | Per-PR list of review-comment dedup ids already forwarded to the session by auto-fix. | Forge comment ids keyed by portable PR keys. Dropping them re-forwards old review comments to the session. |
| `setupTools` | Start option for scratch-folder sessions that enables the setup tools, such as the propose_branch card in the scratch-workspace prompt. | A session option with no account or host identity. |
| `sideSessionNotes` | Delivered side-session notes keyed to the user message uuid that carried them (UI chips). | Transcript-linked history used by the UI and by rewind. Not account- or host-scoped. |
| `sideSessionOffersMuted` | The user muted 'start a side session?' offers for this session. | A per-session user preference. |
